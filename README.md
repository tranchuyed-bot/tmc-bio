# TMC — Minimal Premium

Trang cá nhân tĩnh, không cần cài đặt thư viện.

## Chạy
Mở `index.html` bằng trình duyệt hoặc dùng VS Code Live Server. Để đăng lên GitHub Pages, tải toàn bộ nội dung thư mục lên repository và bật Pages.

## Âm nhạc
Nhạc sử dụng file `music/chill.mp3` có sẵn. Website tự thử phát khi tải xong; Chrome, Safari và nhiều trình duyệt sẽ chặn tự phát có tiếng nếu người xem chưa tương tác. Khi đó, nhạc sẽ phát sau thao tác đầu tiên trên trang hoặc khi nhấn ▶. Không thể bỏ qua hạn chế này bằng JavaScript thông thường.

## Tùy chỉnh
- Thay liên kết mạng xã hội và nội dung trong `index.html`.
- Thay bảng màu, font và khoảng cách trong `style.css`.
- Chỉnh tên và mốc thời gian bài hát trong `app.js`.
- Có sẵn tiếng Việt/Anh, chế độ sáng/tối, responsive mobile/desktop.
